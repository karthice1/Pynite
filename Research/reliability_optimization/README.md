# Reliability-constrained multi-objective optimisation of steel frames (PyNite)

Research code and manuscript for

> *A Reliability-Constrained, Multi-Objective Framework for Cost-Optimal Design of Steel Frame
> Structures under Material and Loading Uncertainty*

Everything in the paper (every number, figure and table) is generated by the scripts in this
folder from seeded random streams.

## Layout

| Path | Content |
|---|---|
| `rbo/sections.py` | W-shape catalogue (AISC Shapes Database v15.0, converted to SI) with a consistency check |
| `rbo/frames.py` | Parameterised planar moment frames, PyNite model builder, five unit load cases |
| `rbo/limit_states.py` | AISC 360-16 resistances, DAM + B1/B2 second-order demands, LRFD and SLS checks |
| `rbo/reliability.py` | Probabilistic model, Monte Carlo limit-state evaluation, reliability indices |
| `rbo/optimize.py` | Constrained GA (Deb's rules) + local search, NSGA-II |
| `rbo/validation.py` | Closed-form benchmarks, OpenSeesPy comparison, full re-analysis Monte Carlo |
| `run_experiments.py` | All numerical experiments (`results/*.json`) |
| `jobs.txt`, `run_all.sh` | All optimisation jobs of the paper (DDO, RBDO, target variants, DDO with h/500, NSGA-II fronts), run on 4 worker processes |
| `make_figures.py` | Figures (`paper/figures`) and LaTeX tables (`paper/tables`) from the results |
| `paper/` | Elsevier `elsarticle` manuscript (`main.tex`, `refs.bib`) |
| `tests/` | Fast regression tests (`python -m pytest tests -q`) |

## Reproducing the paper

```bash
pip install -e ../..            # PyNite from this repository
pip install scipy matplotlib openseespy pytest
cd Research/reliability_optimization
./run_all.sh                    # optimisation runs (about 4 h on 4 cores)
for s in closed_form verify opensees fullmc sensitivity convergence; do   # after run_all.sh
    PYTHONPATH=. python run_experiments.py $s
done
PYTHONPATH=. python make_figures.py
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Key modelling choices

* Five linear PyNite analyses per design (D, L, W and two sway-imperfection cases); any load
  realisation and a global modulus factor are combined exactly by superposition, and
  second-order effects are added with the AISC Appendix 8 B1-B2 amplifiers. This surrogate is
  checked against PyNite's own P-Delta solver, OpenSeesPy and a Monte Carlo study with full
  P-Delta re-analysis of every sample with member-by-member random stiffness.
* Deterministic design: ASCE 7-05 LRFD combinations, AISC 360-16 Direct Analysis Method,
  drift h/400 under D + 0.5L + W, live-load deflection span/360.
* Reliability: 50-year loads after Ellingwood et al. (1980), JCSS steel properties,
  Turkstra load combination, system ULS (all members, both scenarios), drift and deflection
  SLS. Sample average approximation (common random numbers) inside the optimiser; independent
  10^6-sample verification of every final design.
