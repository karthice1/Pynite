\section*{Data and code availability}
All scripts used to generate and verify the PyNite dataset, train the models, run the experiments and produce every figure and table are in the \texttt{research/surrogate} folder of the PyNite fork (\url{https://github.com/karthice1/Pynite}), together with pinned package versions (\texttt{requirements.txt}), the weights of the reported ensemble (\texttt{weights/}) and a one-command reproduction script (\texttt{reproduce.sh}; a \texttt{--quick} option rebuilds all tables and figures from the released weights and result summaries without training any network). The datasets are regenerated deterministically from the seeds in the scripts. [An archived release with a Zenodo DOI will be added before publication.]
